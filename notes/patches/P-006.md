## 4. What must change (content)

**Checker evidence (read-only run 2026-09-27):** `.venv/bin/python scripts/check_compliance.py` →
`R10 FAIL apa_beneath_floats: 7 of 7 floats carry no APA line: figure fig:gate, table tab:models,
table tab:ops, figure fig:tradeoff, figure fig:missdepth, figure fig:boundary, figure fig:busmap`;
R21 identical; totals `PASS=4 FAIL=2 SKIPPED=3 MANUAL=18`.

**Diagnosis.** The regex accepts only three APA-ish markers (a `\apacite` macro, a literal `APA:`, or
`(YYYY).`). All seven lines carry R21's three obligatory elements — student attribution ("created by
Rajan Saha"), creating program, year — in exactly the rule book's example shape, so the FAIL is a
false negative of the gate, not a rule violation. The rule book's own example also fails the current
regex. R10 note: APA is "preferred", not mandatory; the mandatory content is R21's three elements.

**Regex test (scratch `$CLAUDE_JOB_DIR/tmp/p006_regex.py`; the script was not edited).** Test set:
the two credit-line shapes, the R21 example, one APA-style line, and three deliberately defective
lines (no program; no attribution; no year):

| Candidate | Paper lines (2) | R21 example | APA-style | no program | no attribution | no year |
|---|---|---|---|---|---|---|
| current `\\apacite\|APA:\|\(\d{4}\)\.` | fail | fail | pass | fail | fail | fail |
| A: requires "created by … using …, YYYY" | pass | pass | fail | fail (correct) | fail (correct) | fail (correct) |
| year-only `(19\|20)\d{2}` | pass | pass | pass | **pass (wrong)** | **pass (wrong)** | fail |
| C: current OR A | pass | pass | pass | fail (correct) | fail (correct) | fail (correct) |

**Options (author-decision; the author owns the gate):**
- **A — widen the regex to the R21 three-element shape.** Pros: tests what the rule actually
  requires; matches the rule book's example; zero .tex change; rejects the three defective cases.
  Cons: tied to the words "created by … using"; a different but valid phrasing (or an APA line) would
  fail.
- **B — switch the seven lines to APA form so the current regex passes.** Pros: no gate change; APA
  is "preferred". Cons: seven .tex edits (author); APA form for a self-made graphic is not specified
  in App. 3, so the author must still carry attribution + program + year; the gate would then pass on
  a year-in-parentheses alone, without checking attribution or program.
- **C — both shapes accepted (current OR A).** Pros: passes today's lines and any APA conversion;
  still rejects the defective cases. Cons: slightly longer regex.
- Not recommended: year-only — it passes lines missing attribution or program, which is exactly the
  disqualification risk the gate exists for.
