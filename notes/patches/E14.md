   std. The one MAE change beyond std is ridge +F1+F2 (MAE +10.8%); on the gate at ridge's operating point the same

4. **Leakage audit:** F1 was rebuilt from a fresh network with every branch in service for 25 base cases; exact
   match (max error 0.0) — F1 contains only pre-outage information.
