## 3. Old text (verbatim)
- (a) "The base cases were kept if the minimum pre-outage voltage was above 0.94 per unit."
- (b) "The previous implementation of the dataset generator used a lower bound of 0.94 per unit for voltage set points and truncated any set points that fell below that lower bound value at the threshold."
- (c) "After modifying the code and resampling the data, the exact spike at 0.940000 per unit went away, but the number of rows in the narrow band [0.94, 0.945) stayed about the same, moving from 55.5\% to 56.86\%."
- (d) "For instance, in a regeneration of the IEEE 30-bus network that is thermally feasible in the base case, 7.09\% of contingencies fall just above the 0.94 pu limit, while another 15.40\% fall below it."

## 4. What must change
- Method (near a or b) must state, as a design fact: the current generator still draws each voltage setpoint as
  the case118 value ± 0.025 pu and **rejects and redraws** (no longer clips) any draw below 0.94 pu — the same value
  as the under-voltage limit. The clip fix (b/c) changed *how* the floor is enforced, not *where* it is. As written,
  (b)+(c) imply the floor was removed.
- (a) is imprecise: the acceptance test is "at or above 0.94" (accepted bases include N-0 minimum exactly 0.94).
- State the consequence in numbers: 1,016 of the 1,500 accepted bases (67.73%) already have their N-0 minimum in
  [0.94, 0.945) before any outage.
- The PV-bus point must be stated correctly (see MISMATCH in §5): 31.62% of boundary-strip rows have their minimum
  at IEEE bus 76, a generator bus; but only 13.1% of all strip rows have bus 76 sitting *at* its own sampled
  setpoint (within 1e-4 pu). The rest are below setpoint (generator at a reactive limit). So "a large share of the
  strip is the sampler's own setpoint input" is true only for ~13%, not ~32%.
- (d) and every case118-vs-case30 contrast: case30 schedules every generator at 1.00 pu (no setpoint can sit near
  0.94), uses a thermal acceptance filter and a 0.87–0.99 load window. The 56.86% vs 7.09% contrast therefore differs
  in network **and** sampler at once; the causal reading must be scoped accordingly (content owned by `Top5-1.md`).
- The provisional floor-0.95 probe (40 bases, 1 seed: strip 67.3% → 37.0%) must **not** be printed: scratch,
  single seed, no committed script. If the author wants that manipulation in the paper, it is N3 (author decision).
